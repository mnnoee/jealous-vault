# Мейнтейнеры

[English](MAINTAINERS.md) · Русский

## Текущий мейнтейнер

JealousVault поддерживает **mnnoee**.

- Проект: <https://jealousmoon.com/projects/vault/>
- Общая связь: `me@mnnoee.ru`
- Отчёты об уязвимостях: `vault@jealousmoon.com` (резерв `me@mnnoee.ru`), см. [SECURITY.ru.md](SECURITY.ru.md)
- Remote для разработки: Forgejo; remote для релизов: GitHub

Это **соло-проект на best-effort**. За ним нет компании, дежурной смены и гарантированного времени ответа.

## Ожидаемое время ответа

Это ориентиры, а не SLA.

| Канал                           | Ориентир                                                   |
| ------------------------------- | ---------------------------------------------------------- |
| Отчёт об уязвимости             | подтверждение за 3 рабочих дня, оценка за 7                |
| Баг с воспроизведением          | разбор в течение 10 рабочих дней                           |
| Pull request                    | первый review в течение 14 рабочих дней                    |
| Запрос возможности              | без SLA; может быть закрыт как вне области                 |
| Вопрос по сломанному production | best effort; платная поддержка планируется, но её пока нет |

Сроки по безопасности заданы в [SECURITY.ru.md](SECURITY.ru.md) и имеют приоритет для отчётов, отправленных туда.

## Bus factor

Bus factor равен **1**.

Если мейнтейнер становится недоступен:

- код остаётся доступным под Apache-2.0, его можно форкнуть;
- существующие подписанные релизы можно проверить через `build/allowed_signers`;
- гарантий исправлений, релизов и security-патчей от проекта нет;
- сайт и зеркала пакетов могут перестать обновляться.

Не рассматривайте JealousVault как единственную копию данных. Держите независимую копию пароля репозитория, соблюдайте 3-2-1 и регулярно запускайте `test-restore`. Инструмент устроен так, чтобы репозиторий restic оставался читаемым и без агента.

## Решения

- Архитектурные решения записываются как ADR в [docs/adr/ru/](docs/adr/ru/README.md).
- Финальное слово за мейнтейнером; приоритет - безопасность данных и security.
- Публичный продукт полный и распространяется под Apache-2.0; коммерческая работа дополняет его: расширения, плагины, хостинговые сервисы, поддержка и заказная разработка. Границы - в [docs/ru/mvp.md](docs/ru/mvp.md) и [ECOSYSTEM.ru.md](ECOSYSTEM.ru.md).
- Вклады в публичный репозиторий требуют только подписи DCO и принимаются под Apache-2.0. Отдельный [CLA.ru.md](CLA.ru.md) применяется только к коду, принятому в коммерческое расширение.
- Breaking changes регулируются [STABILITY.ru.md](STABILITY.ru.md).

## Как помочь

- Присылайте баги с версией, ОС, версией restic, конфигом без секретов и шагами воспроизведения.
- Сообщайте об уязвимостях приватно, не через публичный issue.
- Улучшайте документацию, тесты и заметки по платформам.
- Запускайте `test-restore` на своих данных и рассказывайте, что не сработало.
- Участвуйте по правилам [CONTRIBUTING.ru.md](CONTRIBUTING.ru.md).

## Финансирование

Сейчас проект без финансирования. Публичный продукт не ограничен: платные расширения, плагины, поддержка, консультации и заказная разработка финансируют работу. Права на коммерческие расширения остаются у их авторов. Политика - в [ECOSYSTEM.ru.md](ECOSYSTEM.ru.md); баг-баунти нет.
