# Архитектурные решения

[English](../README.md) · Русский

ADR фиксирует решение, которое дорого отменять, вместе с контекстом и последствиями. Это не учебник и
не обещание: он объясняет, почему код выглядит именно так, чтобы следующее изменение начиналось с тех
же рассуждений.

Эти записи ведутся на английском и русском. Английская версия первична, русская - параллельный
перевод. Это инженерные заметки для мейнтейнера, а не пользовательская документация.

| ADR                                       | Решение                                       | Статус  |
| ----------------------------------------- | --------------------------------------------- | ------- |
| [0001](0001-toml-config.md)               | TOML для конфигурации                         | принято |
| [0002](0002-separate-run-state.md)        | Состояние запусков в отдельных файлах         | принято |
| [0003](0003-no-daemon.md)                 | Без сервера и долгоживущего демона            | принято |
| [0004](0004-tick-mode.md)                 | `tick` для систем без systemd                 | принято |
| [0005](0005-public-product-extensions.md) | Публичный продукт с независимыми расширениями | принято |

Английские оригиналы: [../README.md](../README.md).

## Когда писать ADR

Пишите ADR, когда изменение:

- меняет формат хранения, формат конфига или публичный CLI так, что отменить это дорого;
- добавляет или убирает процесс, сервис или зависимость с влиянием на безопасность или эксплуатацию;
- меняет границу лицензий или разделение публичного и коммерческого;
- выбирает один дизайн там, где была разумная альтернатива.

Не пишите ADR для исправления бага, нового флага или изменения документации.

## Шаблон

```markdown
# ADR-000N: Название

- Статус: предложено | принято | заменено ADR-000M
- Дата: YYYY-MM-DD

## Контекст

Какие силы действуют и какое ограничение делает решение необходимым?

## Решение

Что выбрано, в одном или двух абзацах.

## Последствия

Что стало проще, что стало сложнее и что теперь явно вне области.

## Рассмотренные альтернативы

Что ещё было правдоподобно и почему отклонено?
```
